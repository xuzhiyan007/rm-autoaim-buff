# handeye_calibration

手眼标定功能包，用于实现机器人末端执行器（手）与相机（眼）之间坐标变换关系的标定。

## 功能描述

本包提供手眼标定的核心功能，通过采集机器人关节状态与相机观测数据，计算相机坐标系到枪管坐标系的变换关系

## 使用方法

### 1. 准备标定环境

确保相机内参已经标定！！！！！！

确保整套自瞄代码已经正常运行，并且以下两个ROS2节点在发布数据：

- **相机节点**：发布图像消息（`/image_raw`）
- **关节状态节点**：发布机器人关节状态消息（`/joint_states`）

可以通过以下命令检查数据是否正常发布：

```bash
ros2 topic echo /joint_states 
ros2 topic echo /image_raw 
```

### 2. 采集标定数据

运行采集节点，移动机器人末端执行器使标定板出现在相机视野中，并采集多组图像与对应的关节状态数据：

```bash
ros2 run handeye_calibration capture_node
```

**操作提示**：
- 在多个不同位姿下采集数据（建议10~20组）,两个位置之间差距越大越。
- 按 ‘s’ 保存，按 'q' 结束标定

### 3. 执行标定计算

数据采集完成后，运行标定计算节点，求解手眼变换矩阵：

```bash
ros2 run handeye_calibration calibrate_node
```

标定结果将打印在终端中，并保存为标定参数文件（ `config/calibration_result.yaml`）。

## 节点说明

| 节点名 | 功能 |
|--------|------|
| `capture_node` | 采集图像与关节状态数据，保存为数据集 |
| `calibrate_node` | 读取采集的数据，执行手眼标定算法，输出变换矩阵 |

## 注意事项

- 标定过程中请保持相机内参已预先标定
- 采集数据时应覆盖机器人工作空间的不同姿态，标定板和机器人相对位置不要移动
